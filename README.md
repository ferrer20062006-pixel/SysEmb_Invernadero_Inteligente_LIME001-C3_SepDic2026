
# Invernadero Inteligente con Ventilación, Cubierta Automática y Riego por Aspersión

## Descripción del proyecto

El Invernadero Inteligente con Ventilación, Cubierta Automática y Riego por Aspersión es un proyecto de sistemas embebidos que busca resolver un problema real: mantener condiciones adecuadas para el crecimiento de las plantas sin necesidad de controlar manualmente cada función del invernadero.

El sistema utilizará la tarjeta de desarrollo STM32F407G-DISC1 como unidad de control principal para coordinar la ventilación, la apertura y el cierre de la cubierta, y el riego por aspersión. Para ello, se integrarán entradas digitales, sensores y actuadores controlados mediante señales PWM, con el propósito de automatizar las funciones principales del prototipo.

Este proyecto permitirá aplicar conocimientos de programación en lenguaje C, configuración de entradas y salidas digitales, generación de señales PWM e integración de hardware mediante STM32CubeIDE. Asimismo, se busca demostrar cómo la automatización puede reducir la intervención manual y facilitar el cuidado de las plantas.

## Objetivo general

Diseñar e implementar un prototipo de invernadero inteligente basado en el microcontrolador STM32F407G-DISC1, capaz de controlar los mecanismos de ventilación, cubierta automática y riego por aspersión mediante la integración de sensores, entradas digitales y actuadores.
